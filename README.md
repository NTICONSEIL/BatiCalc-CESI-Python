# BatiCalc — Python appliqué au BTP

Projet fil rouge de **16 heures** (4 séances de 4 h) destiné aux étudiants de première année de prépa CESI disposant de notions d'algorithmique.

## Contexte

BÂTI33 Construction, entreprise fictive de maçonnerie en Gironde, souhaite créer un outil console pour préparer un chantier de garage : calcul de matériaux, devis, puis suivi des dépenses.

## Progression

| Séance | Notions | Livrable |
|---|---|---|
| 1 | Variables, types, saisies, calculs, conditions | Calculateur de matériaux |
| 2 | Boucles et listes | Devis multiposte |
| 3 | Dictionnaires et fonctions | Programme structuré |
| 4 | Menus, JSON et tests | Application console finale |

## Démarrer

1. Installer Python 3 et VS Code (extension Python).
2. Cloner le dépôt et ouvrir son dossier dans VS Code.
3. Consulter `docs/` puis `seance_01/README.md`.
4. Exécuter `python seance_01/exercices/bati_calc_s1.py` (ou `py` sous Windows).

Aucune dépendance externe n'est nécessaire.

## Organisation

- `docs/` : dossier d'entreprise, données et règles métier.
- `seance_01/` à `seance_04/` : supports et travaux pratiques.
- `donnees/` : fichiers de données d'exemple.
- `tests/` : cas de recette.

**Attention :** les tarifs et calculs sont fictifs et simplifiés ; ils ne constituent pas un devis de construction réel.

Les corrigés enseignants ne sont pas publiés dans ce dépôt étudiant.
